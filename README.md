# 系规备考 · VitePress 文档站

软考**系统规划与管理师（高级）**备考文档站（VitePress 构建）。

## 站点结构

- `docs/basic/`：**基础**（考点精讲），一章一个文档
- `docs/mindmap/`：**思维导图**（后续提供）
- `docs/recite/`：**背诵清单**（后续提供）

## 本地开发

```bash
npm install
npm run docs:dev     # 本地预览
npm run docs:build   # 构建
```

## 部署

推送到 master 分支后，GitHub Actions 自动构建并部署到 GitHub Pages。
