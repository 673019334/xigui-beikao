## 11.1 IT治理

### 1. 核心内容（6项）｜口诀：疯子租架战机

- 风：风险管理
- 子：资源管理
- 租：组织职责
- 架：价值交付
- 战：战略匹配
- 机：绩效管理

> 旧口诀「战价风资绩职」同样可用，选一个顺手的。

### 2. IT治理目标价值（3项）｜口诀：治校风

与业务目标一致、有效利用信息与数据资源、风险管理

### 3. 内涵（4项）｜4. 定义

- 内涵：①目标一致 ②保护权益 ③制度机制 ④治理层负责
- 定义：对 IT 战略、建设运营、投资决策建立的**决策机制与责任框架**

### 5. 目标域｜口诀：EDM管治理，ABDM管管理

- 治理域：**EDM**（评估/指导/监督）
- 管理域：APO（调整规划组织）、BAI（构建获取实施）、DSS（交付服务支持）、MEA（监控评价评估）

### 6. 治理系统组件（7件）｜口诀：原流组文信服人

| 组件 | 作用 |
| --- | --- |
| 原则政策程序 | 行为指南 |
| 流程 | 活动步骤 |
| 组织结构 | 决策实体 |
| 文化道德行为 | 成功因素 |
| 信息 | 运转所需 |
| 服务设施应用 | 技术支撑 |
| 人员技能 | 完成活动 |

### 7. 关键决策（5项）｜口诀：原架基需投

IT原则（高层如何使用IT）｜IT架构（组织逻辑）｜IT基础设施（共享能力）｜业务应用需求（要什么应用）｜投资优先顺序（投多少先投哪）

### 8. 设计因素（11个）

企业战略、企业目标、风险概况、IT相关问题、威胁环境、合规要求、IT角色、**IT采购模式**、IT实施方法、技术采用策略、企业规模

### 9. IT治理任务（5项）｜口诀：全价推新机

全（全局统筹）、价（价值导向）、推（文化助推）、新（创新发展）、机（机制保障）

### 10. 治理活动（4项）｜口诀：统评指监

统筹 → 评估 → 指导 → 监督

### 11. 治理机制（4类）+作用

- 决策机制 = 匹配业绩/战略目标
- 执行机制 = 良好运作
- 风险控制机制 = 降低风险
- 协调机制 = 协调效应

### 12. 体系框架（6部分）

IT战略目标 → IT治理组织 → IT治理机制 → IT治理域 → IT治理标准 → IT绩效目标（闭环）

### 13. 治理架构（3部分）｜14. 层次使命（3层）

- 架构：委员会设置权限 / 委员会构成 / 总部与分支权责边界
- 层次：最高管理层 = 目标一致 + 收益最大化；执行管理层 = 运营高效 + 控成本风险；业务执行层 = 按流程操作

### 15. 治理原则（4类）

透明（清晰可见）｜简单（易于操作）｜适合（与组织匹配）｜公正（公平不偏）

### 16. 治理 vs 管理

治理做**正确**的事（董事会）；管理**正确**地做事（管理层）；治理是管理基石，**管理在治理既定模式下行动**（治理画跑道，管理跑比赛）

### 17. 陷阱词速查

- 「全权/完全」→ 单选多为错项
- 「文化/人员/信息」→ 是组件不是决策目标
- 「清晰 = 透明，好操作 = 简单」
- 问目标选 3 件套，问核心内容选 6 件套

## 11.2 IT审计

### 18. 审计范围（4维）

总体范围、组织范围、物理范围、逻辑范围

### 19. 审计风险模型｜口诀：固控检

**总体审计风险 = 固有风险 × 控制风险 × 检查风险**

- 固有风险：不考虑内控时发生错报的可能
- 控制风险：内控没能防止/发现/纠正错报
- 检查风险：审计程序没查出重大错报（审计方可控）

> **关键关系：固控越高 → 检查风险需压得越低（反向）**

### 20. 审计方法（6）｜口诀：问卷查看测码

| 方法 | 动作 |
| --- | --- |
| 访谈法 | 当面问 |
| 调查法 | 问卷/函证 |
| 检查法 | 查文档 |
| 观察法 | 看现场 |
| 测试法 | 运行验证 |
| 程序代码检查法 | 审代码 |

### 21. 审计技术（4）

风险评估技术、审计抽样技术、计算机辅助审计技术（CAAT）、大数据审计技术

### 22. 审计工作底稿（3）｜口诀：综业备

- 综合类（总体计划、审计报告等）
- 业务类（具体项目审计记录）
- 备查类（法律法规、内控制度等参考）

### 23. 审计流程（4阶段）｜口诀：准施结后

审计准备（定目标范围方案）→ 审计实施（取证评价）→ 审计终结（出报告提意见）→ 后续审计（跟踪整改）

> 对应治理活动：计划 → 取证 → 报告 → 跟踪

### 24. IT内部控制审计

组织层面IT控制审计 → **IT一般控制审计**（组织管理、系统开发维护、信息安全、操作运行、数据）→ **应用控制审计**（输入、处理、输出控制）

### 25. IT专项审计（6类）｜口诀：生开运网项数

信息系统生命周期审计｜信息系统开发过程审计｜信息系统运行维护审计｜网络与信息安全审计｜信息系统项目审计｜数据审计
