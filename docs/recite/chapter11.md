## 二、逐项背诵

### Q1. IT治理的主要目标？

**答案**：与业务目标一致、有效利用信息与数据资源、风险管理

| 口诀 | 目标 |
| --- | --- |
| 治 | 与业务目标一致 |
| 理 | 有效利用信息与数据资源 |
| 风险 | 风险管理 |

### Q2. ★ IT治理的核心内容？

**答案**：风险管理、资源管理、组织职责、价值交付、战略匹配、绩效管理

| 口诀 | 内容 |
| --- | --- |
| 疯 | 风险管理 |
| 子 | 资源管理 |
| 扭 | 组织职责 |
| 架 | 价值交付 |
| 成 | 战略匹配 |
| 机 | 绩效管理 |

### Q3. ★ IT治理活动的主要任务？

**答案**：全局统筹、价值导向、文化助推、创新发展、机制保障

| 口诀 | 任务 |
| --- | --- |
| 全 | 全局统筹 |
| 价 | 价值导向 |
| 推 | 文化助推 |
| 新 | 创新发展 |
| 机 | 机制保障 |

### Q4. IT审计风险主要包括哪些？

**答案**：固有风险、控制风险、总体审计风险、检查风险

| 口诀 | 风险 |
| --- | --- |
| 固 | 固有风险 |
| 制 | 控制风险 |
| 总 | 总体审计风险 |
| 检 | 检查风险 |

> 关键关系：固有、控制风险越高 → 检查风险要压得越低；总体审计风险 = 固有 × 控制 × 检查。

### Q5. ★ 常用审计方法包括哪些？

**答案**：访谈法、调查法、检查法、观察法、测试法、程序代码检查法

| 口诀 | 方法 |
| --- | --- |
| 访 | 访谈法 |
| 调 | 调查法 |
| 查 | 检查法 |
| 观 | 观察法 |
| 测 | 测试法 |
| 程序 | 程序代码检查法 |

### Q6. ★ 常用的IT审计技术包括哪些？

**答案**：风险评估技术、审计抽样技术、计算机辅助审计技术、大数据审计技术

| 内容 | 口诀 |
| --- | --- |
| 风险评估技术、审计抽样技术、计算机辅助审计技术、大数据审计技术 | 风险审计大 |

### Q7. 审计工作底稿一般分为哪些？

**答案**：综合类、业务类、备查类工作底稿

| 口诀 | 底稿 |
| --- | --- |
| 综 | 综合类工作底稿 |
| 业 | 业务类工作底稿 |
| 备 | 备查类工作底稿 |

### Q8. ★ 审计流程一般分为哪些？

**答案**：审计准备 → 审计实施 → 审计终结 → 后续审计

| 口诀 | 阶段 |
| --- | --- |
| 准 | 审计准备 |
| 时 | 审计实施 |
| 终 | 审计终结 |
| 后 | 后续审计 |
