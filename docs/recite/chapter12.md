## 二、逐项背诵

### Q2. ★ 服务战略规划的主要活动？

**答案**：规划设计活动、服务目录管理、服务需求识别、服务级别设计

### Q3. ★ 服务目录管理活动步骤？

**口诀：小肯定想发详**

1. 成立管理小组
2. 划分服务清单
3. 确定服务类别与代码
4. 编制服务详述
5. 评审并发布服务目录
6. 完善服务目录

### Q4. ★ 客户对信息系统服务的需求？

**口诀：暴力可怜服务**（谐音联想：暴=报告、力=利益、怜=连续）

| 口诀 | 需求 |
| --- | --- |
| 可 | 可用性需求 |
| 怜 | 连续性需求 |
| 服 | 服务能力需求 |
| 务 | 信息安全需求（防务） |
| 力 | 价格需求（利益） |
| 暴 | 服务报告需求（报告） |

### Q5. ★ 可用性的相关指标？

| 指标 | 公式 |
| --- | --- |
| 平均无故障时间 MTBF | 系统运行时间 ÷ 系统在运行时间内的故障次数 |
| 平均故障修复时间 MTTR | 系统故障耗时 ÷ 故障次数 |
| 平均故障间隔 MTBSI | 平均无故障时间 + 平均故障修复时间 |

> 关键关系：**MTBSI = MTBF + MTTR**

### Q7. 典型服务报告的内容？

**口诀：绩报量趋势未来**

| 口诀 | 内容 |
| --- | --- |
| 绩 | 按照既定服务水平目标衡量的服务绩效 |
| 报 | 主要工作的绩效报告 |
| 量 | 工作的特点和工作量信息 |
| 趋势 | 某段时间的趋势信息 |
| 未来 | 报告中要包含未来计划工作的相关信息 |

### Q8. ★ SLA、OLA、UC 的定义？

| 协议 | 定义 |
| --- | --- |
| 服务级别协议 SLA | 在一定成本控制下，为保障服务的性能和可靠性，服务供方与客户间定义的一种双方认可的协议 |
| 运营级别协议 OLA | 与某个内部信息服务部门就某项信息系统服务所签订的后台协议 |
| 支持合同 UC | 服务供需双方签订的有关服务实施的正式合同 |

> 记忆三角：SLA 对客户承诺、OLA 内部部门间、UC 支撑服务的正式合同。

### Q9. ★ 服务设计实现的主要活动？

**口诀：服务结构过人**

1. 服务模式设计
2. 人员要素设计
3. 资源要素设计
4. 技术要素设计
5. 过程要素设计

### Q10. 常见的信息系统服务模式？

| 模式 | 具体形式 |
| --- | --- |
| 远程服务 | 远程集中监控、远程技术支持 |
| 现场服务 | 上门技术支持、驻场技术支持 |

### Q11. 信息系统服务模式的设计考虑因素？

1. 选择的服务模式与客户可用性、连续性、安全性等方面的服务需求一致
2. 服务供方的人员和资源配置与所设计的服务模式相匹配
3. 服务供方具备同时提供多种服务模式的能力，能够根据客户需求的变化，及时对服务模式进行调整

**关键词：模式一致、人员匹配、多种模式**

### Q12. ★ 人员要素设计的内容？

**口诀：只瞧鸡**

1. 人员岗位和职责设计
2. 人员绩效方案设计
3. 人员培训方案设计

### Q13. 人员要素设计的目标？

1. 确保服务团队组织架构与服务需求和服务模式相适应
2. 确保配置的服务人员数量能同时满足服务和成本两方面的需求
3. 确保服务人员的能力持续满足服务的需求
4. 保持服务人员稳定的工作状态
5. 保持服务人员的连续性

**关键词：架构适应、数量满足、能力满足、稳定状态、人员连续**

### Q14. ★ 信息系统服务团队的主要岗位？

### Q15. ★ 人员绩效方案设计的活动？

**口诀：只愿等周期**

1. 确定绩效指标
2. 明确考核信息来源
3. 制定绩效指标考核方法
4. 定义绩效考核周期
5. 设计绩效考核策略

### Q16. 人员培训方案设计的活动？

**口诀：虚实成果**

1. 培训需求分析
2. 培训内容设计（管理培训、技术培训、工具培训、过程培训、交付和应急培训）
3. 培训实施过程设计
4. 制订培训计划
5. 确定培训形式
6. 规范培训纪律
7. 培训效果评价方法设计
