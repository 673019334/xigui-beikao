# 默写练习工具

> 逐题默写、即时核对答案，考前冲刺专用。支持按章节筛选、随机/顺序出题、答案相似度自评。

::: tip 使用提示
1. 选择章节（或"全部章节"）→ 点击「出题」
2. 先默写，再点「提交答案」看相似度，或点「显示答案」直接对照
3. 点「隐藏答案」可重新默写；「上一题 / 下一题」回顾历史题目
:::
